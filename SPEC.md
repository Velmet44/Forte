# Forte — Music Player · Project Specification

> A focused, professional desktop music player for local audio files.
> Built in Python. Ships as a single windowed app.

---

## 1. Identity

| | |
|---|---|
| **Name** | Forte |
| **Tagline** | *Your music. No noise.* |
| **Platform** | Windows / macOS / Linux (desktop window, not full-screen) |
| **Language** | Python 3.11+ |

## 3. Visual Design

### 3.1 Design Philosophy

Forte should look like it was designed by a small indie studio, not generated by AI.
The aesthetic is **dark, warm, and analogue-inspired** — think hardware equalizers and
vinyl sleeves, not Spotify's sterile blue. Every pixel has a reason to exist.

The signature element: **a horizontal waveform bar visualizer that lives inside the
progress bar track itself** — bars grow upward from the seekable scrubber line,
making seek + visualize a single unified object. This is the one thing no one else does.

### 3.2 Colour Palette

```
--bg-base:       #1A1A1E   (near-black, slightly warm — the window background)
--bg-panel:      #212127   (sidebar / playlist panel)
--bg-elevated:   #2A2A32   (cards, hover states, input areas)
--bg-scrubber:   #18181C   (the progress bar track)
--accent:        #E8A838   (warm amber — the ONE colour that punches)
--accent-dim:    #C48A22   (hover/active state of accent)
--text-primary:  #F0EDE8   (near-white, warm tint — titles, track name)
--text-secondary:#8E8C88   (muted — artist name, timestamps)
--text-disabled: #4A4847   (inactive controls)
--border:        #2E2E38   (subtle separators)
--danger:        #C0392B   (error states only)
```

### 3.3 Typography

```
Display (track title):  Inter 600, 18px, --text-primary
Artist / album:         Inter 400, 13px, --text-secondary
UI labels / buttons:    Inter 500, 12px
Timestamps / metadata:  "JetBrains Mono" or system monospace, 11px, --text-secondary
Playlist items:         Inter 400, 13px, truncated with ellipsis
```

Fonts ship bundled (Inter is open source). Fall back to system sans-serif on load failure.

### 3.5 Interaction Design Rules

- **No flat grey buttons.** Every button has a clear active state (amber highlight or icon brightens).
- **Hover states are subtle** — `--bg-elevated` background on hover, no border flash.
- **Playing track in playlist** is highlighted with an amber left-border (3px) and `--text-primary` colour. All others are `--text-secondary`.
- **Progress bar / scrubber**: thin 3px track. The thumb is a 10px amber circle. It appears only on hover (clean look when not interacting).
- **Volume knob**: a horizontal slider, 80px wide. Icon changes at 0% (muted), 1–50% (low), 51–100% (high).
- **Album art placeholder**: when no art is embedded, show a subtle geometric pattern generated from the track title's hash — each song gets a unique gradient tile. Never a blank grey square.
- **Drag and drop**: drag MP3/FLAC/WAV/OGG files onto the playlist panel → they appear instantly. Drag to reorder within the list.
- **Animations**: progress bar updates every 200ms (smooth). Visualizer runs at ~30 FPS. Window open/close: no janky flicker.
- **Scrollbar**: custom thin scrollbar (4px) in `--border` colour. No OS default chrome.

## 4. Features (Complete List)

### 4.1 Playback Engine
- [ ] Play / Pause (toggle, Space key)
- [ ] Stop
- [ ] Seek by clicking / dragging the progress bar
- [ ] Volume control (slider + mute toggle, M key)
- [ ] Next track (→ key, button)
- [ ] Previous track (← key, button) — restarts if >3s in, goes back if <3s
- [ ] Skip forward 10s (Shift+→)
- [ ] Skip back 10s (Shift+←)
- [ ] Supported formats: MP3, FLAC, WAV, OGG, M4A

### 4.2 Playlist
- [ ] Add files (button + Ctrl+O)
- [ ] Add folder (loads all supported audio recursively)
- [ ] Remove selected track (Delete key)
- [ ] Clear playlist
- [ ] Drag-and-drop files in from OS
- [ ] Drag-to-reorder within playlist
- [ ] Right-click context menu: Play Next / Remove / Show in Explorer
- [ ] Search / filter (type in search box → live filter, Ctrl+F)
- [ ] Double-click to play
- [ ] Shuffle mode (randomises queue, remembers original order to unshuffle)
- [ ] Repeat Off / Repeat All / Repeat One (cycle with button)
- [ ] Save playlist as `.m3u8`
- [ ] Load `.m3u8` playlist file

### 4.3 Now Playing Panel
- [ ] Track title (full, wraps if needed)
- [ ] Artist and album from ID3/Vorbis tags
- [ ] Album art (embedded in file, 300×300, rounded corners 12px)
- [ ] Generative placeholder art (unique gradient per track when no art embedded)
- [ ] Duration display (elapsed / total, monospace)
- [ ] Progress bar with integrated waveform visualizer

### 4.4 Waveform Visualizer
- [ ] Real-time FFT bar visualizer rendered inside the progress bar track area
- [ ] ~40 frequency bars, amber (`--accent`) at full height, dimming toward `--bg-elevated` at base
- [ ] Bars animate smoothly (lerp toward target, not instant jump)
- [ ] Falls back gracefully if numpy unavailable (static waveform thumbnail from file)
- [ ] Pauses animation when track is paused (bars slowly shrink to flat)

### 4.5 System Tray
- [ ] Forte icon in system tray when running
- [ ] Tooltip shows current track name + artist
- [ ] Right-click tray menu: Play/Pause · Next · Previous · Show Window · Quit
- [ ] Closing the window minimises to tray (doesn't quit)
- [ ] Quit only from tray menu or Ctrl+Q

### 4.6 App State & Persistence
- [ ] Remembers last playlist on reopen (`~/.forte/session.json`)
- [ ] Remembers last played track + position
- [ ] Remembers volume level
- [ ] Remembers shuffle / repeat state
- [ ] Recently played list (last 20 tracks, shown in right-click menu)

### 4.7 Keyboard Shortcuts

| Key | Action |
|---|---|
| `Space` | Play / Pause |
| `→` / `←` | Next / Previous track |
| `Shift+→` / `Shift+←` | Skip +10s / -10s |
| `M` | Mute toggle |
| `Ctrl+O` | Add files |
| `Ctrl+F` | Focus search |
| `Ctrl+Q` | Quit |
| `Delete` | Remove selected track from playlist |
| `Ctrl+S` | Save playlist |

### 4.8 Settings Panel (lightweight modal)
- [ ] Theme: Dark (default) / Light
- [ ] Crossfade duration: 0s / 1s / 2s / 3s (dropdown)
- [ ] Minimise to tray on close: toggle
- [ ] Show file extensions in playlist: toggle

## 6. Build & Release

```bash
# Install deps
pip install -r requirements.txt

# Run from source
python main.py

# Package (Windows)
pyinstaller --onefile --windowed --icon=assets/icon.ico main.py

# Package (macOS)
pyinstaller --onefile --windowed --icon=assets/icon.icns main.py
```

The `dist/forte` binary (or `forte.exe`) is the demo link target — host on GitHub Releases.
